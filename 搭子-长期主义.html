📝 时间 P&L 周复盘模板
📋 KEEP / DELEGATE / SKILL / AUTOMATE / STOP
• KEEP：本周要继续做的高价值时间投入
• DELEGATE：可以交给别人（包括 AI）的事
• SKILL：把它变模板 / SOP 的候选
• AUTOMATE：能跑脚本就走脚本
• STOP：这件事不再发生，就别再回去做
⏳ Hard Rule：第二次出现的同类任务评估模板化，第三次原则上 Skill 化。

🗺️ 长期主义三阶段成长路线👆 点击阶段展开/收起
📌 阶段 1 · Day 0-7 · 觉察▾
目标：把所有任务分类，看清多少是「现在不做就焦虑」，多少是「半年后还有价值」。
• 任务 1：今天第一次记录 5 件事，每件标 长线 / 短视 / 噪音
• 任务 2：识别 3 个你最容易掉进的「短视触发器」（群里@ / 红点 / "先回一下"）
• 任务 3：写下「如果不做这件事，3 个月后会怎样？」多数答案是"没事"，那就是噪音
📌 阶段 2 · Day 8-30 · 切分▾
目标：所有任务只进 5 个去向：亲自做 / AI 先做我拍板 / AI 独立我抽检 / Skill / Automation。
• 任务 1：把上周所有任务重分类进 5 个去向，写下「我自己应该 STOP 的 3 件事」
• 任务 2：选一个重复任务，今天就把它 Skill 化（哪怕只是一个 chat prompt 模板）
• 任务 3：选一个最耗你时间的会议，问自己「这次如果我不出席，会发生什么？」
📌 阶段 3 · Day 31-90 · 复利▾
目标：每周只做 1 次《个人时间经营周复盘》，完成 KEEP / DELEGATE / SKILL / AUTOMATE / STOP 五张清单。
• 任务 1：完成第一次周复盘（15 分钟）
• 任务 2：累计 SKILL 化 ≥ 3 项 + Automation ≥ 1 项
• 任务 3：设一条 Hard Rule：「T3/T4 任务不上我本人日程」
